## Space Blaster

A 2d top down plane shooting game demo.

### Tech Stack

- Unity
- VS Code/Visual Studio
- C#

### Several Interesting Implementation

- Enemy Wave: enemy spawning and path finding with way points using ScriptableObject(SO) and Prefab(Variants)
- Camera Shake: screen shake when player takes damage
- Paritcle System Usage: explosion particles
- Game UI: main menu and game over menu
- Scene Management: switch between main menu, gameover menu and actual game level
- Music and SFX Setup: damage and shooting sound effects with background music
- Singleton Pattern: for scoring and audio
- Basic Projectile Setup: shooting mechanic
- Background Scrolling

Note: many thanks to GameDev TV video instructions.
